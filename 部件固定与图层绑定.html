「固定不同部件要不同图层」——要，但固定的应该是角色，不是物理层
如果做成「16 个部件 = 16 个死图层」，衣服层就只有一层，第二套衣服无处安放，衣柜直接死掉。
正确做法：角色固定三层（本体 / 衣服 / 饰品），物理层可多——衣柜就是若干个衣服层，同一时刻只有一层激活，其余算库存不渲染。
现在的层规则
本体层 1 个，不可增删
衣服层 1 个，不可增删
饰品层 N 个
→ 只能替换，不能存
需要的层规则
本体层 1 个，锁死
衣服层 N 个，激活 1 个
饰品层 N 个，全部叠加
→ 能替换，也能存
两条不变量：
① 同一部件在同一时刻最多激活一次——不会出现两件上衣同时穿在身上。
② 部件归属永远不变——衣柜只换内容，不改标签；所以换装不可能把眼睛挪到衣服层上。
所以「现在的实现能做到吗」
部件固定、部件绑图层 —— 已经做到了，而且玩家连角色都改不了。
脱衣 / 穿衣 / 外套 / 裤子 —— 已经能做到，靠隐藏衣服层 + coat 与 top 两层叠。
眨眼 / 说话 / 眉毛 / 左右腿 / 左右手 —— 做不到，缺 5 个部件（brow、arm_l、arm_r、leg_l、leg_r）+ 帧 + 锚点。
衣柜变装 —— 做不到，衣服层被锁成 1 个，存不下第二套。
形态不一也能共用动态 —— 做不到，因为部件只是标签，没有肩点胯点，同一个抬腿角度贴到不同人身上就偏。
