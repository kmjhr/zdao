# 纸上岛 · zdao

个人开发的像素 OC 世界观察器。核心概念「拼豆成灵」：在 29×29 拼豆图纸上拼 Q 版小人，每格记「颜色 + 部件」双值，产出结构化双矩阵；角色进入地图后由玩家观察，可拖动、可戳。

定位是**观察蚂蚁箱**——玩家不扮演角色，而是那个伸手去拨弄箱子的存在。

## 手建模

`04-脚本/手建模/` 下是纯 numpy 的 SDF 建模 + 三渲二渲染管线，输出 56×72 像素 sprite。

```powershell
python 04-脚本/手建模/make_hand_3d.py        # 像素版
python 04-脚本/手建模/make_hand_3d_views.py  # 四视角
python 04-脚本/手建模/label_hand.py          # 标注图
```

几何参数、改法与已知坑见 `04-脚本/手建模/手建模-定稿参数.md`。
