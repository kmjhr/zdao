## 1. 四层结构与原则

| 层 | 名称 | 默认可见性 | 装什么 | 核心规则 |
|---|---|---|---|---|
| ① | 私密宇宙 | 私密 | OC、剧情、纪念册、演出、物件、世界观卡 | 所有内容默认只属于自己；先有可晒的东西，才谈社交 |
| ② | 好友圈 | 好友 | 岛门、手信、联机约戏 | 进岛必须授权；手信进入对方 OC 记忆；约戏边界取交集 |
| ③ | 社区广场 | 有条件公开/公开 | 图纸市场、演出录像、剧情片段、世界观模板 | 异步为主，无冷启动、无运营成本 |
| ④ | 公开页 | 公开 | OC 展示柜、精选演出、图纸名片 | 陌生人可见、不可进岛；是展示与获客出口 |

四层不是四个独立产品，而是同一份内容的四种出口：内容先在①生长，作者逐条决定是否进入②③④。**默认私密**，此前讨论的“默认公开”作废。

纪念册属于①私密层，是 OC 与玩家共同记忆的事实源。约戏成品同时写入双方①的纪念册各一份，并在②保留一份“合作演出”索引；③④只能引用快照，不能读取纪念册原文。

## 2. 不做清单

以下功能本期明确不做，原因是它们与“私密宇宙 + 异步社交”的定位冲突，且会显著抬高成本与审核风险：

| 不做 | 理由 |
|---|---|
| 实时大厅 | 需要实时同步与在线运营，违背“异步为主、无运营成本” |
| 频道聊天 / 陌生人私信 | 骚扰与未成年风险最高，且与“岛门授权”模型冲突 |
| 公会 / 阵营 | 会把关系变成组织，稀释“OC 与玩家”的私人关系 |
| 排行榜 | 把创作变成数值竞争，和“宇宙私密、关系沉淀”相反 |
| 实时多人同屏 | 本期一律不做；岛内只有主人与授权访客，且默认只读 |
| 多人实时共创宇宙 | 本期不做；联机约戏是异步协作，不等同实时共创 |
| 陌生人进岛 | 公开页只展示，不提供任何进岛路径 |

**边界说明**：联机约戏是“两家 OC 同台演出”，允许异步生成与异步确认，不做实时同屏操作；任何需要实时多人同步的形态都不进入本期。

## 3. 可见性四档与转发

### 3.1 四档定义

| 档位 | 谁能看 | 典型用途 | 能否被搜索 | 能否进岛 |
|---|---|---|---|---|
| 私密 | 仅自己 | 草稿、私密纪念册、未完成演出 | 否 | 否 |
| 好友 | 已同意的好友 | 好友可见的 OC 卡、回放、图纸 | 否 | 需另开岛门 |
| 有条件公开 | 持链接/兑换码/满足条件者 | 凭码领取图纸、限定回放、活动展示 | 按设置 | 否 |
| 公开 | 任何人 | 公开页、广场作品、名片 | 是 | 否 |

“有条件公开”的条件类型：兑换码、关注后可见、申请后可见、限时链接。条件由作者选，平台只提供能力，不默认放宽。

### 3.2 可见性矩阵

| 内容 | 私密 | 好友 | 有条件公开 | 公开 |
|---|---|---|---|---|
| OC 卡（不含边界原文） | 自己 | 好友 | 持条件者 | 任何人 |
| 角色岛与岛内日常 | 自己 | 需岛门授权 | 不可见 | 不可见 |
| 纪念册 | 自己 | 按条目授权 | 不可见 | 不可见 |
| 演出回放 | 自己 | 好友 | 持条件者 | 任何人 |
| 图纸/物件 | 自己 | 好友 | 持条件者 | 任何人 |
| 世界观模板 | 自己 | 好友 | 持条件者 | 任何人 |

### 3.3 转发 / 转载（“要可以转”）

【用户原话】“（向所有人公开，条件公开，私人，要可以转）”。**“要可以转”按“允许转发/转载”理解，语义待确认（Q1）**，建议默认：

- 每个作品独立开关“允许转发”，默认**关闭**；公开作品也默认关闭。
- 开启后只允许**原样转发**并保留作者署名与来源链接，不允许改图、去署名、二次售卖。
- 有条件公开作品转发后，接收者仍需满足原条件；私密/好友作品不因转发变成公开。
- 作者撤销分享或下架后，新转发失效；已保存到本地的图片不可追溯，页面需提示。
- 转载到站外平台视为“二次发布”，需作者单独授权；未授权按举报处置。

## 5. ① 私密宇宙（底座）

### K01 私密宇宙与默认私密

- **规则**：所有 OC、剧情、纪念册、演出、物件、世界观卡创建时 `visibility=private`；不存在“创建即公开”。公开是逐条动作，且必须经过 K13 的可见性设置。
- **隔离**：全部实体带 `universe_id`；他人视图只能读取 `public_snapshot`，不能读取原宇宙。纪念册、记忆原文、OC 边界字段永不进入快照。
- **产品表现**：宇宙首页显示“仅自己可见”；分享/公开入口需要二次确认；关闭分享不影响岛内使用。
- **验收标准**：新内容默认私密；未公开不出现在任何他人视图；OC/纪念册/演出均带 `universe_id`；关闭分享不影响私密内容可用。

## 6. ② 好友圈

### K02 好友关系、请求、分组与拉黑

- **关系模型**：好友必须双向、需同意；关注为单向、只覆盖公开内容（见 K12）。好友与关注互不自动转换。
- **请求**：`待处理 → 同意/拒绝/取消/7 天过期/因拉黑失效`；拒绝后 24h 内不可重复申请；请求通知只发一次。
- **组织**：备注仅自己可见 ≤12 字；分组可自建；好友 200、待处理 50、分组 20。
- **拉黑**：双方不可搜索、申请、进岛、评论、引用；解除拉黑只回到“已解除”，不恢复好友；正在访问的 3 秒内断开。
- **验收标准**：好友必须双向同意；请求 7 天过期、拒绝后 24h 冷却；备注仅自己可见；拉黑后双方不可搜索/申请/进岛/评论/引用；解除拉黑不恢复好友。

### K03 岛门授权与串门

- **授权粒度**：一次性（本次访问有效）、长期（默认 30 天，可续）、白名单（指定好友长期有效）；按宇宙分别授权，不因“好友”自动全开。
- **区域范围**：全岛 / 公共区 / 指定场景；卧室、纪念册、未公开演出默认不可进入。
- **主人在场**：三选一——主人在场（访客能看到主人 OC）、隐身观察（主人可看访客行为，访客不知）、离岛（仅按授权规则自动接待）。默认“主人在场”。
- **访客权限**：只读参观（默认）与可互动（点击 OC、送礼、留言）分开授权；任何模式都不能编辑布局、带走物件、修改关系。
- **撤销与踢出**：主人可随时撤销或单方踢出，3 秒内断开；踢出后 24h 内不可再次申请该岛；访问留痕保留 30 天，主人可清空。
- **验收标准**：岛门默认关闭；授权粒度含一次性/长期/白名单；区域范围可选；主人可选在场或隐身观察；只读与可互动分开；撤销 3 秒内断开并留痕；踢出立即生效。

### K04 手信赠送与记忆归属

- **赠送**：把自拼道具/图纸寄给好友的某个 OC；收件方必须已授权可收礼。手信携带 `赠送者、赠送时间、来源宇宙、物件来源`。
- **送达表现**：收件 OC 收到后有一次性反应（查看/试穿/摆放）；反应写入该 OC 记忆，摘要双方可读，私密细节只归收件方。
- **记忆归属**：赠送者看到“已送达/已收下”状态；收件方可回礼；记忆条目在双方纪念册各记一条，内容为共同摘要。
- **退信与过期**：7 天未领取自动退回，退回不扣次数；拒收需选择原因（默认不通知赠送者具体原因）；拉黑后未领取手信立即退回。
- **防骚扰**：单日 ≤3 封、同一好友 7 日 ≤10 封；重复物件去重提示；被拒收 3 次后 7 天内不可再向该好友赠送。
- **验收标准**：手信携带赠送者、时间、来源宇宙；收件 OC 记忆可引用且双方可读摘要；拒收/过期原路退回；单日 ≤3、同好友 7 日 ≤10；拉黑后不可再送。

### K05 联机约戏

- **邀约**：发起方选剧本与各 ≤2 个 OC，发送邀约；24h 未响应自动过期；对方可接受/拒绝/改期。
- **剧本来源**：AI 生文（按各自世界观卡）或模板；生成前双方确认剧本大纲，生成后任一方可要求重写 1 次。
- **边界**：双方 `never_do` 取并集、软边界取交集；冲突裁决顺序为平台安全 → 双方硬禁忌 → 各自世界观卡 → 剧本设定；无法同时满足则拒绝该情节或改写。
- **否决权**：双方创造者对成品各有一票否决；否决后不写入纪念册，可保留草稿供私下查看。
- **取消与超时**：任一方可中止；中止不产生半成品、不扣次数；超时未确认自动取消。
- **归属与署名**：成品双方共有，署名为“A 宇宙 × B 宇宙”，参演 OC 标注创造者；对外分享需双方同意。
- **验收标准**：邀约 24h 超时；剧本来源 AI/模板；双方创造者各有一票否决；边界取交集、`never_do` 取并集；取消不留半成品；成品双写双方纪念册并署名。

## 7. ③ 社区广场（异步层）

广场只展示“作者主动公开”的内容，默认不推荐私密宇宙里的任何东西；不做实时互动，不做陌生人私信。

### K06 图纸市场

- **上架**：作者选图纸、色号版本、授权方式（免费/兑换码/有条件公开）、是否允许二次修改。
- **领取**：领取后生成独立副本进入领取者自己的宇宙；副本保留“原作者、来源链接、色号版本”，不得移除。
- **二次修改**：允许改色、改局部、改部件；修改后的作品仍标“基于某某图纸”，原作者不承担修改责任。
- **搬运限制**：同一账号短时间批量领取/转售触发限流；站外搬运需作者单独授权；未署名搬运按 K14 处置。
- **下架**：作者下架后停止新领取；已领取副本可继续使用，但不可再分发。
- **验收标准**：领取条件可选免费、兑换码、有条件公开；领取后可在自己宇宙二次修改但不得移除来源署名；下架后已领取副本可用但不可再分发；搬运可举报。

### K07 演出录像广场

- **上架**：只允许已公开且过审的回放；作者选公开/有条件公开；默认关闭下载。
- **观看**：只读播放，倍速/暂停；不能导出原件；评论区按 K14 管理。
- **授权范围**：观看不等于可改编；引用到他人纪念册需作者授权，且只存快照。
- **下架/举报**：下架后链接 404；举报按 K14。
- **验收标准**：仅公开且过审回放；作者可设公开/有条件公开；观看不可下载原件；举报下架；转发受 K13 限制。

### K08 剧情片段广场

- **内容**：文本片段 + 可选一张分镜；用于展示写作与世界观，不是完整剧本。
- **脱敏**：公开前必须走脱敏预览，移除私密记忆原文、真实联系方式、未公开 OC 边界。
- **使用**：他人可引用为灵感，不可一键导入自己的宇宙；导入需作者授权并生成副本。
- **验收标准**：片段不含私密记忆原文；公开前必须脱敏预览；可引用不可直接进他人宇宙；举报下架。

### K09 世界观模板广场

- **内容**：只含世界观卡结构（语言腔调、时代氛围、拼豆色板、OOC 基准、扩展字段的空模板）与风格标签，不含个人 OC、剧情与私密设定。
- **领取**：生成独立副本，保留模板来源与作者；可改字段，不可移除来源标注。
- **下架**：下架后停止新领取；已领取副本可继续用。
- **验收标准**：模板只含世界观卡结构与风格标签，不含个人 OC/私密设定；领取生成副本并保留来源；作者可下架。

## 8. ④ 公开页

公开页是“展示与获客出口”，不是社交广场：陌生人能看、能关注/申请好友，但不能进岛、不能私信。

### K10 公开页与 OC 展示柜

- **展示内容**：OC 卡（不含边界原文）、精选演出、图纸名片；上限 OC 12、演出 6、图纸 12。
- **可见性**：默认私密；作者逐项选择公开/有条件公开；公开页本身不等于全宇宙公开。
- **陌生人路径**：查看 → 关注或申请好友 → 对方同意后才可能进入好友圈；无“直接进岛”。
- **下架**：作者可随时下架单项或整页；下架后链接 404，快照标记“已下架”。
- **验收标准**：默认私密；展示上限 OC 12 / 演出 6 / 图纸 12；陌生人可见不可进岛；下架后链接 404；他人 OC 需授权；展示字段不含边界原文与记忆。

### K11 精选演出与策展

- **来源**：只从公开且过审的回放中选；不选私密/好友/有条件公开内容。
- **策展口径**：新鲜度、叙事完整度、边界合规、风格多样性；每期 ≤20；标准对外公开。
- **作者权**：作者可拒绝入选或随时撤下；精选不改变归属与授权。
- **验收标准**：仅从公开且过审回放选；策展标准公开（新鲜度/完整度/合规/多样性）；作者可拒绝精选；精选不改变归属；每期 ≤20。

### K12 图纸名片与陌生人入口

- **名片**：公开图纸缩略图、作者署名、风格标签、来源链接；不展示 OC 边界、记忆、私密宇宙。
- **陌生人入口**：只能“关注”或“申请好友”；被关注者可关闭被关注入口；申请仍走 K02。
- **防冒充**：昵称与知名作者高度相似时提示；认证标识只对真实作者开放；冒充按 K14 优先处理。
- **验收标准**：名片只展示公开图纸与作者署名；陌生人只能关注或申请好友，不能进岛；被关注者可关闭入口；名片不暴露 OC 边界与私密宇宙。

## 9. 全层规则

### K13 可见性四档与转发/转载

- **四档**：私密 / 好友 / 有条件公开 / 公开；每条内容独立设置，父子内容不自动继承（宇宙公开不等于纪念册公开）。
- **权限联动**：可见性决定谁能看；评论、复制、借用、转发各自独立开关，默认关闭。
- **转发**：默认关闭；开启后仅原样转发并署名；作者撤销后新转发失效；站外二次发布需单独授权。
- **审计**：每次可见性变更记录时间、操作者、影响范围；批量修改需二次确认。
- **验收标准**：四档即时生效；可见性与评论/复制/转发权限一致；转发默认关闭，开启后仅原样转发并署名；撤销后新转发失效。

### K14 举报—审核—处置—申诉

| 阶段 | 时限（建议） | 结果 |
|---|---|---|
| 受理 | 即时 | 返回受理编号 |
| 初审 | 24h 内 | 通过/驳回/转人工 |
| 处置 | 48h 内 | L1 提示 / L2 内容下架 / L3 账号限权 / L4 封禁或移交 |
| 申诉 | 7 天内提交 | 维持/减轻/撤销，给理由 |

入口：公开页、市场、回放、评论四处可达；举报人保密；恶意举报限流；L3/L4 人工复核并留审计；未成年与敏感内容一律转人工，具体口径需产品/法务确认（Q8/Q9）。

**验收标准**：公开页/市场/回放/评论可举报；24h 初审、48h 处置；L1–L4；7 天申诉；记录可查；未成年与敏感内容转人工。

### K15 通知聚合与离线降级

- **聚合**：好友请求、手信、来访、约戏邀请、评论/点赞按类型聚合；同一对象 24h 合并 1 条；举报结果必达。
- **免打扰**：默认 23:00–08:00 本地时区；仅静音推送，应用内可查；安全类通知不受限。
- **离线**：点赞、留言草稿、分组备注本地先行，联网后按时间合并；拉黑、撤销授权、踢出、撤销分享联网优先，离线置灰不假装成功。
- **一致性**：好友动态/广场不可用显示缓存并标“可能延迟”，不伪造新内容。
- **验收标准**：通知按类型聚合、免打扰不推送；离线本地先行、联网按时间合并；动态不同步标“可能延迟”；拉黑/撤销授权/踢出联网优先。

### 10.1 状态机

- **好友请求**：`pending → accepted / rejected / cancelled / expired / invalidated(blocked)`
- **好友**：`active → removed → blocked → 解除拉黑（仅回到 removed）`
- **岛门授权**：`inactive → active(once/long/whitelist) → expired / revoked / kicked`
- **手信**：`sent → delivered / rejected / returned / expired`
- **约戏**：`invited → accepted → preparing → generated → approved / vetoed → published → ended / aborted`
- **可见性**：`private → friend / conditional / public → 撤销回 private`；任何变更写审计。
- **举报**：`submitted → triaged → reviewing → actioned / dismissed → appeal → upheld / reduced / overturned`

## 12. 待确认问题

1. **Q1 “要可以转”的语义**：按“允许转发/转载”理解；建议默认关闭、开启后仅原样转发并署名，站外二次发布需单独授权。
2. **Q2 岛门长期授权时长**：建议 30 天可续；是否允许永久授权待定，默认不提供永久。
3. **Q3 隐身观察是否告知访客**：建议不告知但留访问记录，主人可查；是否强制提示待产品确认。
4. **Q4 手信记忆归属**：建议共同摘要双份、私密细节归收件方；是否允许赠送者删除自己那份待定。
5. **Q5 约戏剧本谁出**：建议支持 AI 生文与模板，双方各确认一次；是否允许第三方剧本待定。
6. **Q6 约戏成品归属**：建议双方共有、分享需双方同意；商业化与署名顺序需产品/法务确认。
7. **Q7 公开页展示上限**：建议 OC 12 / 演出 6 / 图纸 12；是否按等级扩容待定。
8. **Q8 未成年保护**：建议未成年账号默认关闭陌生人关注/评论、公开页仅好友可见；年龄门槛与实名流程需产品/法务确认。
9. **Q9 版权与搬运**：本文只写授权与署名规则，不写法律结论；站外搬运、二次售卖与侵权处置需法务确认。
10. **Q10 注销后的引用**：建议公开内容下线、约戏成品保留双方署名快照、30 天后清理；具体期限与删除义务需法务确认。
