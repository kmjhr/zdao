## 0. 产品定位

### 0.1 一句话定位
把玩家的文字（小说/同人/OC 设定）变成**像素拼豆漫画与舞台剧**，让 OC 在专属的**角色岛（沙盘宇宙）**里活过来：有记忆、有情绪、守人设，还会在玩家不在时过日子。

### 0.2 核心幻想
"我的 OC 从我的文字里活了过来，它记得我说过的每句话，只在我的宇宙里存在。"

### 0.3 设计支柱（三条）
1. **私人化 / 唯一性**：每个玩家的宇宙内容都来自自己的文字与 OC，没有两个玩家玩到一样的游戏——大厂商业模式复制不了。
2. **深度关系**：玩家养的不是数值，是关系（OC 与玩家、OC 与 OC）；情感是最深的沉没成本。
3. **AI 原生内容生长器**：AI 负责内容生产（剧情/事件/图纸/记忆），系统负责确定性渲染（一致、可复现、低成本）。

### 0.4 核心原则与边界（不做清单）
- **作品开放，世界私密**：陌生人最多看到公开展示柜，进岛永远需要好友授权。
- 不做：实时大厅 / 频道聊天 / 公会 / 排行榜等大厂式社交。
- 不做：多人同屏大地图、重度数值氪金。
- 私人性是护城河，社交只放大它，不稀释它。

## 1. 目标用户与市场

### 1.1 痛点
- AI 写文工具已是巨量内容池（豆包/ChatGPT/各类小说生成器），但**没有"文 → 可视化漫画/演绎"的完整闭环**。
- 市面"文生漫画"工具是文生图逐格生成：画风崩、角色不连贯、没有游戏性、无情感绑定。

### 1.2 用户画像
- AI 写手 / 同人创作者 / OC 创作者（核心）
- 同人 CP 圈 / 谷子收藏圈（高传播性）
- 像素/手工（拼豆）爱好者
- 桌面宠物用户（情感陪伴需求）

### 1.3 竞品与空白

| 现有形态 | 缺什么 | 本产品补什么 |
|---|---|---|
| 文生漫画工具 | 角色不一致、无游戏性 | 拼豆矩阵保证 100% 一致；演出会留下痕迹 |
| AI 聊天角色卡（Glow/酒馆类） | 只有聊天，无游戏目标/无视觉 | 角色岛沙盘 + 演出 + 沉淀 |
| 拼豆模拟器 | 只有拼，无世界 | 拼的东西进入叙事（道具进戏） |
| 桌宠（shimeji 类） | 无记忆的通用皮套 | 记得岛上一切的 OC，守 OOC 边界 |

## 2. 核心玩法

### 2.1 三时刻循环（写 → 活 → 演 → 沉淀）

| 时刻 | 名称 | 玩家做什么 | 系统做什么 |
|---|---|---|---|
| ① 写 | 纸上 · 创作台 | 导入/撰写文字，完善 OC 卡 | 文→角色提取、生成拼豆图纸 |
| ② 活 | 岛上 · 日常 | 上岛观察、互动、送礼物 | OC 按角色卡过日子（现实时间同步） |
| ③ 演 | 戏台 · 演出 | 写/选一段剧情，看演出，可改可重演 | 文本→剧本→像素舞台剧（确定性渲染） |
| ④ 沉淀 | 纪念册 | 回顾、整理官方剧情 | 演出留下痕迹：纪念册/关系/岛与道具 |

**闭环**：演出沉淀出的新记忆 → 成为下一次创作的素材 → 循环加深。

### 2.2 纸上 · 创作台
- **文导入**：导入小说/同人/OC 设定文本 → AI 提取角色（外貌/性格/关系）、世界观、剧情节点、情感弧线。
- **OC 卡**：结构化人设，含显式 **OOC 边界**（性格特质 / 雷区 / 说话风格 / 绝对不能做的事）。
- **关系网**：OC 之间可挂关联（CP / 家人 / 对手 / 师生），关系决定互动剧本。
- **拼豆图纸**：Q 版全身 32×32 起步、48×48 进阶的分层图纸（发型/头/身体/服装/配件），像素更细、可放大创作，可手动调整。
- **设定即任务**：新手引导 = 补全角色卡（教用户 + 喂 AI，一举两得）。

### 2.3 岛上 · 日常（沙盘）
- 动森式小岛：OC 按角色卡自由活动（作息/散步/做自己的事），**现实时间同步**。
- 玩家可随时上岛：观察、点击互动、送礼物。
- **回忆碎片**：AI 偶尔让 OC 想起过去，生成内心独白或小重演（不可预测的惊喜源，守 OOC 边界）。
- **人设守护日志**：AI 把"差点破界"的瞬间写成 OC 的内心独白（"她张了张嘴，那句'留下来'还是咽了回去"）——约束系统变成情感素材。
- **离线事件报告**：玩家不在时岛上继续过日子，回来收到 AI 生成的事件总结（动森式期待感）。

### 2.4 戏台 · 演出（核心高潮）
- 写/导入一段剧情（或调用自接 API 按世界观生成）→ 系统拆分为剧本（场景/动作/台词/情绪）→ 像素小人在岛上演（走位/动作/对话/镜头）。
- **AI 只决定内容，画面由引擎确定性渲染**：角色 = 固定矩阵，动作 = 姿势库，背景 = 模板——一致、可复现、成本可控。
- **剧本循环**：演出后切到剧本视图，玩家可改台词/动作/顺序 → 重新演绎；改完的版本进纪念册成为"官方剧情"。
- **拼豆道具进戏**：演出用的道具是玩家亲手拼的豆（如"那束花"）——创作进入叙事，情感核弹。

### 2.5 沉淀系统
- **纪念册时间线**：演出与重要互动的"官方剧情"自动成册。
- **关系天平**：OC 间关系双向可视化（A→B 与 B→A），事件改变天平（演出/送礼/日常互动）。
- **岛与道具改变**：演出会真实改变岛（演了"搬家"戏，屋子真的换位置）。

### 2.6 多宇宙系统
- **宇宙 = 世界观卡 + 角色岛 + OC 群 + 专属纪念册 + 专属物品与色板**（语言腔调、氛围、拼豆色板都随世界观走）。
- **宇宙管理台**（书架/星图）：建宇宙、切换、看解锁节奏。
- **跨宇宙客串**：A 宇宙 OC 去 B 宇宙做客——**守主人的世界观，双方 OOC 边界取交集（更严）**；世界观冲突本身就是戏。
- **解锁节奏（防"一堆空岛"）**：完成当前宇宙关键剧情 → 解锁下一个宇宙。宁可 3 个深宇宙，不要 10 个空岛；跨宇宙事件把玩家拉回旧宇宙（宇宙间有引力）。
- 数据模型从第一天带 `universe_id`，架构即多宇宙。

### 2.7 长期不腻五支柱映射

| 支柱 | 在《纸上岛》的落点 |
|---|---|
| 内容可变 | 文导入+AI 续写、新宇宙=新风格、跨宇宙奇遇、回忆碎片 |
| 积累回报 | 纪念册、关系天平、OC 图鉴、宇宙图鉴、豆色收集 |
| 目标分层 | 当下宇宙主线 / 跨宇宙事件 / 解锁新宇宙 / 每日设定任务 |
| 新鲜感注入 | 演出、回忆碎片、离线事件报告、赛季式新模板 |
| 社交拉力 | 好友动态、手信、联机约戏、作品被点赞收藏 |

### 2.8 创新功能清单

| 功能 | 说明 | 支柱 | 优先级 |
|---|---|---|---|
| 人设守护日志 | 被边界拦住的瞬间→内心独白 | 情感/内容 | P0 |
| 剧本循环 | 写→演→改→再演，玩家是导演 | 可变/积累 | P0 |
| 设定即任务 | 新手引导=补全角色卡 | 目标/新鲜 | P0 |
| 关系活地图 | 关系变化可视化+事件演化 | 积累/社交 | P1 |
| 边界松紧滑杆 | 日常严格，剧情高潮临时松绑 | 情感高潮 | P1 |
| 离线事件报告 | 我不在时岛上的日子 | 新鲜/回访 | P1 |
| 演绎录像导出 | 舞台剧录成短视频分享 | 传播/社交 | P1 |
| 跨宇宙客串 | 不同宇宙 OC 串门写信 | 可变/新鲜 | P2 |

## 3. 社交系统

### 3.1 信任漏斗四层

| 层级 | 可见性 | 功能 |
|---|---|---|
| ① 私密宇宙 | 默认仅自己 | OC/剧情/纪念册/演出/道具 |
| ② 好友圈 | 好友授权 | 岛门互访、手信、联机约戏、好友动态 |
| ③ 社区广场 | 全部玩家（异步） | 图纸市场、演出分享、剧情片段、世界观模板、点赞收藏 |
| ④ 公开页 | 陌生人 | OC 展示柜、精选演出、图纸名片 |

### 3.2 好友圈细节
- **岛门**：好友授权后进岛（像现实串门），非公开逛街。
- **手信**：拼的道具寄给好友的 OC，对方 OC 记得"这是谁送的"——拼豆创作进入跨玩家叙事。
- **联机约戏（Killer）**：两家 OC 同台演出，各守各创造者的 OOC 边界（交集规则），成品进双方纪念册。
- **好友动态**：时间线展示好友 OC 的新演出/新图纸（回访理由的社交版）。

### 3.3 社区广场
异步为主：无冷启动、无运营成本。图纸市场（取用别人的拼豆图纸）、演出录像、剧情片段、世界观卡模板。

### 3.4 实施顺序
P0：公开页（晒）+ 简单好友 → P1：岛门互访 + 手信 + 好友动态 → P2：联机约戏 + 图纸广场。
原则：**先让自己有可晒的东西，再开好友，最后才开广场**——社交是放大器，不是发动机。

## 4. 桌宠（伴随层）

### 4.1 定位
岛是家，桌面是散步。把 OC 带出岛，常驻用户桌面（透明置顶窗口、像素帧动画）。

### 4.2 能力
- **记忆同步**：桌宠知道岛上剧情与玩家互动，会突然"提起"（回访钩子）。
- **守 OOC**：桌宠言行过同一套边界校验。
- **情绪可视化**：岛上事件影响情绪，反映在桌宠表现（低落时趴桌角），可被"哄好"。
- **多只同屏**：多只 OC 同屏互动（对视/偷看/吃醋）——CP 截图即传播。
- **交互**：摸摸头、送道具、表演一段、**回岛**（右键菜单即回访钩子）。
- **动画零手绘**：动作 = 矩阵局部变换 + 帧插值（拼豆确定性渲染复用）。

### 4.3 接口预留
OC 状态接口（记忆/情绪/剧情）从第一天设计为可被外部程序读取；桌宠是第一个出口，后续动态壁纸、锁屏小组件共用同一接口。

## 5. 美术规格（Q版全身 · 像素拼豆）

### 5.1 Q 版全身标准
- 头身比 2~3 头身（头约占一半高度）；正/侧/背三视图。
- 全身才能撑起关键分镜：初遇蹲下、门口对峙、拽衣领的吻。

### 5.2 拼豆矩阵（像素密度）
- **32×32 标准**（3 头身，头约 16 格）：日常快速拼的默认画布。
- **48×48 进阶**（精细创作）：可表现发型层次、眼神、衣褶、小道具，支持"放大创作"。
- 像素更小 = 可放大创作：分辨率分档，标准档保住拼豆手感，进阶档满足细节党。
- 快速拼对冲耗时：模板 + 智能填充 + 局部放大/笔刷批量，避免大画布劝退。
- 豆色系统：色板随世界观定制；豆色本身是可收集资源。

### 5.3 分层换装
发型 / 头 / 身体 / 服装 / 配件分层组合——可换装、保一致性、自由创作深度翻倍。

### 5.4 色板随世界观（示例）
| 宇宙 | 风格 | 色板 |
|---|---|---|
| 政谋 | 朝堂·文言腔 | 深青·赭石 |
| 青春疼痛 | 小镇·白话细腻 | 暖米·栗棕 |
| 谷子日常 | 舞台·轻快 | 多巴胺彩 |

### 5.5 模板与自由模式
预设图纸（含底图色号）+ 自由画布双路径；AI 每天可批量生成新图纸。

### 5.6 动画与演绎渲染
- 动作 = 姿势库（站/坐/蹲/走/牵手/拽衣领）+ 矩阵变换。
- 漫画/舞台剧 = 确定性渲染（角色矩阵 + 背景模板 + 布局），AI 只决定内容。

## 6. AI 系统

### 6.1 能力模块

| 模块 | 输入 | 输出 |
|---|---|---|
| 文→结构提取 | 文本 | 角色卡、关系网、剧情节点、情感弧线 |
| 角色→拼豆图纸 | 角色卡/文本 | 32×32 / 48×48 分层图纸（像素化） |
| 剧情→分镜→演绎 | 文本/剧本 | 动作指令序列（走位/姿势/台词/镜头） |
| 记忆系统 | 事件流 | 结构化记忆 + 向量检索（OC 记得什么） |
| 行为引擎 | 角色卡+当前状态 | OC 下一步意图（日常模板 + LLM 补充） |
| 续写引擎 | 世界观+记忆 | 新剧情/新事件/新图纸/离线报告 |

### 6.2 OOC 约束机制
- OOC 边界为显式字段，所有 AI 行为/对话/剧情**先过边界校验**再输出。
- **守护日志**：被拦下的瞬间转为角色内心独白（约束→情感素材）。
- **边界松绑**：玩家触发的高潮事件可临时放宽边界，破界瞬间为最强情感冲击。

### 6.3 记忆系统
- 事件沉淀为"共同记忆"（纪念册条目），驱动回忆碎片、关系天平、桌宠提起。
- 成本控制：结构化事件 + 向量检索混合，避免全量历史进上下文。

### 6.4 自接 API（BYO）
- 玩家可绑定自己的大模型 API（按世界观生成小说、对话）。
- 收益：成本可控（玩家自付）、隐私、模型自由选择；降级策略：模板+本地规则兜底。

### 6.5 成本与降级
- 日常行为用状态机模板（零成本），特殊事件才调 LLM。
- AI 故障/超时 → 确定性模板行为兜底，UI 不留白。

## 7. 系统与技术

### 7.1 数据模型（核心实体）

| 实体 | 关键字段 | 说明 |
|---|---|---|
| universe | id, name, world_card(世界观卡), color_palette, status | 宇宙（多宇宙入口） |
| oc | id, universe_id, name, profile(角色卡), ooc_boundary, matrix(图纸矩阵), mood | OC，从属宇宙 |
| relation | from_oc, to_oc, type, value | 关系网（双向关系天平） |
| scene(剧本) | id, universe_id, nodes(分镜序列) | 演绎剧本 |
| performance | id, scene_id, props, result | 一次演出记录 |
| memorial | id, universe_id, type, content, ts | 纪念册时间线 |
| item | id, universe_id, matrix, source(diy/preset) | 物品（拼豆/预设） |
| memory | oc_id, event, embedding | OC 记忆 |

### 7.2 经济系统（物品双轨）
- **拼豆 DIY**：玩家亲手拼角色、道具、装饰（核心创作）。
- **游戏预设**：商店/任务/事件/图鉴解锁获取。
- 物品参与玩法：送礼影响关系、道具进入演出（不只是装饰）。

### 7.3 技术栈
- 前端：Vue3 + Canvas（拼豆编辑器/沙盘/演出引擎/桌宠窗口）。
- 后端：Midway(Node) + MySQL（用户/宇宙/OC/纪念册）。
- AI：自接大模型 API（结构化输出约束 + 确定性渲染）。
- 数据：本地存档 + 云同步；桌宠为独立透明窗口，读取 OC 状态接口。

### 7.4 模块划分
- 前端：创作台 / 沙盘引擎 / 演出引擎 / 漫画阅读器 / 桌宠窗口 / 社交页。
- 后端：AI 编排（提取/图纸/剧本/记忆）、存储、账号与好友。

### 7.5 性能与成本风险
- 演出渲染与沙盘并发 → 分帧/懒加载；LLM 调用 → 模板优先 + 缓存；多宇宙数据增长 → 按 universe 分区。

## 8. 版本规划

### 8.1 MVP（2~3 周）
- **范围**：1 个宇宙（青春疼痛，素材现成）+ 2 个 OC（姐姐 + 我）；创作台（导入文→OC 卡→图纸）；岛上（自由活动/互动/送礼）；戏台（一段文本→一场演出）；沉淀（纪念册 +1、关系天平变动）。
- **不做**：多人、社交、桌宠、多宇宙切换（架构预留）。
- **验证指标（一条）**：玩家会不会为了"再看一次演出、再写一段剧情"回到岛上。

### 8.2 P1
多宇宙解锁（宇宙 2/3）、剧本循环、人设守护日志、关系活地图、离线事件报告、边界滑杆、公开页 + 好友、录像导出。

### 8.3 P2
联机约戏、图纸广场、桌宠、跨宇宙客串、动态壁纸等接口出口。

### 8.4 里程碑
M1 拼豆编辑器 + 文导入角色提取 → M2 岛上沙盘（自由活动/互动） → M3 演出引擎（文本→演绎） → M4 沉淀+验证 → M5 多宇宙与社交。

### 8.5 风险与对策

| 风险 | 对策 |
|---|---|
| 创作回报配比（拼的投入配不上回报） | 快速拼（模板+智能填色）与自由拼双路径；"活过来"有仪式感 |
| 多宇宙摊大饼 → 全荒 | 解锁节奏 + 宇宙间引力（跨宇宙事件） |
| AI 幻觉 / OOC 失控 | 显式边界校验 + 确定性渲染 + 模板兜底 |
| 版权（拼他人 IP） | 主打原创 OC；谷子角色仅同好圈"致敬模板" |
| 自嗨无验证 | 先找同圈人试玩，验证回访意愿 |
| API 成本 | BYO API + 模板优先 + 缓存 |

### 提取结果示例
**姐姐（养母/"姐姐"）**
- 外貌：深灰大衣 · 栗色卷发 · 穿西装好看
- 性情：轻声细语、从不红脸、克制成习惯
- 道德枷锁：好=还恩情而非本心 → 躲
- 爆发点：拽衣领、凶且抖、扣后脑勺

**我（叙述者）**：12 岁被领养、一住十年（现 22 岁左右）；试探→疏远→醉后逼问→搬走威胁→被吻。

**剧情 7 节点**：初遇 → 日常相依 → 试探靠近 → 她察觉（换花）→ 疏远冷战 → 醉后对峙 → 爆发之吻（张力归零）。

**6 个分镜**：初遇 / 床头红糖圆子汤 / 花瓶换花 / 门口抱臂抿唇 / "你喝多了" / 拽衣领的吻。
