图层即部件：可以改，而且比逐格标记好
新建图层时选这个图层是什么部件，取消格子级标记矩阵，同一部件可开多层（头发1 / 头发2）。这是把「作坊式刷标签」换成「工程式建层」。
现在 · 格子级标记
一个图层里混着多种部件
每画一格都要先选「部件笔刷」
裁剪后标签跟着格子走、会被切碎
想给头发分前后层，做不到
→ 双层选择：先切层，再切笔刷
改后 · 图层级绑定
一层只属于一个部件
建层时选一次，之后只管画
标签是整层的，搬不走也切不碎
头发可开两层：头发1 飘、头发2 不动
→ 单层选择：切到哪层就画哪个部件
新建图层的流程
点「＋图层」→ 只弹一件事：这层画什么。
① 选部件
头 头发 眉毛 眼睛 嘴巴 躯干 左臂 右臂 左腿 右腿 上衣 外套 裤子 鞋 袖子 饰品
固定 16 个，不可新增、不可改名。灰＝本体，黄＝衣服，紫＝饰品。
② 自动编号
选了「头发」
已有 0 层 → 建「头发」
已有 1 层 → 建「头发2」
已有 2 层 → 建「头发3」
同部件上限 4 层。够分前后、外挂、飘带。
③ 落位
所属角色由部件自动推导
头/头发/眉/眼/嘴/躯干
左右臂/左右腿 → 本体
上衣/外套/裤/鞋/袖 → 衣服
饰品 → 饰品
玩家不用再选角色，少一层判断。
同一部件多层的价值：动效可以分开绑
这是你这个改动真正解决问题的地方——原来一个头发只能整体动。
头发1 · 后发
绑「风摆」：走路时 ±1px 横向位移，2fps
头发2 · 刘海
不绑动效：跟头一起走，永远不动
上衣1 / 上衣2
两套衣服，靠「激活」互斥，衣柜就落在这一层
动效绑定的是层，不是部件名
{ layerId: 'L7', part: 'hair', seq: 1, anim: 'sway' }
同一部件两层可以有完全不同的动态，互不干扰；换装时只换层的激活状态，动效声明不用改。
要补的三条规则，不然会乱
本体至少留 1 层：头 / 躯干 不可删到 0，否则人没了；其余本部件可删干净。
衣服可以 0 层：这是「脱光」的表达，正好你要的脱衣。上衣 0 层 = 没穿上衣，外套 0 层 = 没穿外套。
同部件上限 4 层：不限的话有人开 20 层头发，侧栏直接崩。
这个改法的代价，要说清楚
层数会从 5 涨到 15 以上
一个人物拆满 16 部件就是 16 层，侧栏必须按角色分组折叠，否则全摊开根本找不到。
画错层要靠搬，不能靠改标签
以前改格子标签就行，现在得整块搬到另一层。所以要补一个「把选区移到某层」的工具，不然返工成本很高。
姐姐的旧数据怎么办
她现在的 part 矩阵里只有 8 种：hair / head / eyes / mouth / coat / top / pants / shoes。
迁移脚本按部件反推：每个部件生成一层，把该部件的格子复制进去，层序按原图层顺序。
8 种部件 → 8 层，一个像素都不用重画。coat 和 top 原来在同一层里互补，拆开后仍不重叠，视觉完全一致。
