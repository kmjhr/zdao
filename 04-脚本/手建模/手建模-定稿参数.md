## 指序（硬规范）

拇指在左、掌心朝外时：**拇指 → 食指 → 中指 → 无名指 → 小指**
食指贴虎口，中指最高（27），无名指 23.5，食指 22.0，小指最矮（17.5）。
任何修改都必须遵守这个顺序；此前的错误是把真实手左右镜像了。

## 渲染管线（五步）

1. SDF 建模：圆角盒手掌 + 鱼际椭球 + 手指胶囊，`smin` 平滑并集，`smax` 减法切指缝槽
2. 正交射线求交：−z 步进 1.1，二分夹逼 9 次
3. SDF 梯度求法线
4. n·L 硬切三档 + `N[:,2] < 0.22` 判黑（这就是描边）
5. 4× 超采样 → 取众数降采样 + 黑色占比 ≥22% 直接判黑（保证描边闭合）

配色：亮 `#EACBA4` / 中 `#D2B294` / 暗 `#C8A47C` / 描边 `#1A1A1A`

## 改几何的注意事项

- **两个脚本各存一份独立 SDF**（`FINGERS` / `SLOT_X` / `PALM` 都重复定义），改几何必须**两处同步改**，否则像素版和四视角版不一致。
- 改手指 x 坐标后，`SLOT_X`（指缝槽中点）要跟着改，否则槽会卡到手指上。槽中点 = 相邻两指 x 的平均值。
- 手指**不要拆成两段胶囊**：两段半径稍有差异（3.3→2.8）就在交界处鼓出竹节，`smin` 调小也救不回来。单段胶囊才是光滑圆柱。
- 指缝窄于 1.0 格时，降采样会把两根手指判成同一块肉，描边贴到曲面变成阶梯。要直线就得留 ≥1.2 格缝。
- 超采样建图后取众数，1 格宽的缝才不会被平均掉成中间色。
