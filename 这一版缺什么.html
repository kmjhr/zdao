数据层全了，播放层是空的
17 部件、选区、撤销、两档、导出全都做出来了。但 26 个动效、4 个性格、18 个动作表情——一个都不会真的动。这不是 bug，是没写。
最硬的证据，作者自己写在代码里
previewMotion()（第 4211 行）点击试播时弹出的提示是：
「试播「…」900ms（编辑器最小预览；真实播放由演绎系统负责）」
而它实际做的事，是把那一层横向左右晃一下：pvx = Math.sin(pr*π*4) * (1-pr) * cell * amp（第 1674 行）。
走路不会迈腿，眨眼不会闭眼，说话不会张嘴。所有动效预览都是同一套正弦抖动。
第一档 · 有壳无芯（四项）
数据存得很漂亮，但没有一个消费者。这是这一版最大的缺口。
1 · 动效没有播放器
26 条 MOTIONS 登记得很全（id / group / parts / how / duration / loop / trigger / launch），但没有任何代码读 how 去执行。挂载到层只是写一个 animation 对象。
缺的是：一个按 motion_id 分发的执行器——走路走腿交替、眨眼换闭眼帧、说话嘴帧交替。
2 · 性格只是存了个名字
PERSONALITIES 四套参数写得很准（turn / swing / step / breath / blink / hair），但全文件没有任何计算读过它们。PERSONALITIES[pid] 只被用来取 .desc 显示在界面上。
那个「收 / 放」滑杆（tune −1~1）也只是存着。所以现在选「活泼」和选「慵懒」，画面上看一模一样。
3 · 动作表情勾选没人读
artwork.character.actions[id] 存了每个动作开不开（第 3230 行），但没有任何地方查这个值决定播不播。
所以勾了「挥手」和没勾，行为上没有任何差别。
4 · 帧存了，但没有消费者
addFrameFromLayer()（第 4233 行）能把当前层像素存成一张「自绘帧」素材，存进 motion_assets。但没有任何代码拿这张帧去替换层画面。
帧素材本质上是一堆躺在数组里的数据。
这四项加起来意味着：26 个动效 + 4 个性格 + 18 个动作表情 + N 张帧，全都没有接上画面。
界面看起来什么都有，但它是「配置器」，不是「动画器」。
第二档 · 跟定好的规格冲突
画布档位不对
SIZE_OPTIONS = [16, 24, 32, 40]，没有 29，默认选 32。
规格是：默认 29×29，可选 15 / 21 / 29 / 40，自定 8–64。
29 是当初从市面拼豆图纸定的基准，缺了它，画出来的角色和岛上 1 豆 = 1 设备的换算对不上。
一打开就是空白
没有任何示例角色。新手进来只看到 32 格空网格，不知道「17 层该长什么样」「一只手臂占几格」。
旧版里的姐姐 29×29 数据这一版没了。
官方帧全是占位
六条 builtin.eyes.closed / mouth.open / mouth.smile / mouth.o / brow.up / brow.down，note 逐条写着「内置占位，待接官方素材」。
点开看到的是空素材 + 缺像素标记。
动作表情放错地方
定的是「底部同一台预览台、两个页签」，现在塞进了右侧「设置」页里（第 4119–4120 行）。
后果：没有一处能「整人播放」，只能一层一层试。
第三档 · 缺的创作工具
水平镜像 ✗
画好左腿复制不出右腿。四条对称部件全靠手画两遍。
整层偏移 ✗
整层画偏一格只能重画。这是最高频的返工。
魔棒 / 连通选择 ✗
有矩形选区，但要点选「一只手的全部像素」还得手框。
必填检查 ✗
头 / 躯干缺失不报。建了层但没画，也能导出上岛。
影子 ✗
按轮廓生成的半透明椭圆，运行时的事，编辑器不做也对。
多草稿 ✗
只有一个 autosave 槽（papersisland.editor.autosave.v2），新建就覆盖上一个。做第二个 OC 必须先把第一个导出。
没列进缺失的：撤消 / 层锁定 / 层合并 / 移到层 / 复制到层 / 反选 / 两档 / 风险确认 / PNG+JSON 导出 / 自动保存 —— 这些都有，而且做得比我原先建议的更细（选区是多矩形真补集，移动有冲突策略）。
顺带一个隐患，不是缺功能是埋雷
撤销是全量 JSON 快照 × 50 步（serializeArtwork() 第 1299 行）。每笔操作都序列化整个作品。
32×32 × 17 层的 JSON 约 200 KB，50 份约 10 MB 常驻内存。换到 40×40 或层数更多，每次落笔都要序列化一遍，会开始卡。
建议：把快照压成只记「改动的那一层 + 索引」，或者降到 20 步。
补齐顺序
① 动效执行器（性格 → 参数 → 每帧算位移/换帧）。这一步不做，前面所有设计都是纸面。
② 把性格接进参数计算，让它真的改变摆幅与步频。
③ 动作表情搬到预览台，给一个整人播放的地方。
④ 尺寸改回 29 默认；塞一个示例角色，让人知道目标长什么样。
⑤ 镜像、整层偏移、必填检查，三个小工具，都是半天级。
⑥ 多草稿，等前面稳定了再做，因为它要动存储层。
