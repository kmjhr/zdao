一个角色卡要装六层，性格不属于「信息」
先给结论：性格不是填在信息栏里的，它和「雷区 / 说话风格」是一类；而编辑器现在这两类一个字段都没有。
先说现状，免得你以为只是「放错位置」
编辑器 index.html 里搜「姓名 / 简介 / 标签 / 性别 / 生日」= 0 处；搜 7 个刻度 = 0 处。
它现在是一个像素画 + 动效编辑器，不是角色卡编辑器。卡的信息和性格在文档里有结构，在代码里没有入口。

为什么性格不该塞进「信息」
信息 = 身份事实
姓名、生日、性别。
填错只是难看，改完世界不变。
一次填完，之后基本不动。
性格 = 行为设定
改一个刻度，他接下来几天的行为全变。
已有关系和记忆会显得「不像他」。
该带提示、该进撤销栈、不该随手改。
所以：「信息」和「性格」放同一个表单里，会让人以为改性格跟改生日一样轻。实际上前者是改了会变一个人，后者只是改个数字。
这两样东西该在同一个页面出现，但必须有明显分隔和不同的话术。
编辑器页签怎么分（建议）
色板 ｜ 图层 ｜ 角色 ｜ 设置 ｜ 资料 ← 新增

【角色】= 表现层，随选中层变化
　动作风格 · 他动起来什么样
　预览栏 · 点一下就看
　动效素材

【资料】= 设定层，跟选中哪层无关
　① 基本信息　姓名 / 性别 / 生日 / 简介 / 标签
　② 性格　　　7 刻度 + 冲突方式，或 24 词选 3–5
　③ 边界　　　价值观 / 雷区 / 永不做 / 说话风格
　④ 关系　　　跟谁、什么关系、多深
判断依据还是那条：换一个图层还看得见，属于这个人的整体；换了就消失，属于这一层。资料页四项全都跟图层无关。

位置
现在怎么写 / 该改成什么
§12.3 @1928
现在：「详情页『性格』页签」两种填法。
问题：详情页是世界里观察时点的，不是创作时填的。
改成：详情页只只读展示 3–5 个词 + 一个「去编辑器改」；填法搬到编辑器资料页。
§12.10 @2180
现在：X13 十四项全是「怎么画」（撤销、对称笔、描边、猜部件…）。
缺口：没有一条讲「卡的信息填在哪」。
改成：补一项 X13.15「卡资料与性格表单」。
一个必须先定的选择
A. 编辑器只画不算人：资料/性格/边界都放在别处（创作台表单），编辑器只交出一张矩阵。
B. 编辑器当角色工作台：加「资料」页签，画完就地填完，一张卡在同一个文件里收口。
我倾向 B——文档 §12.10 说「编辑器是整个产品的入口，目标是十五分钟内画出一个能动的 OC」，如果填资料要跳出去，这十五分钟就断了。
