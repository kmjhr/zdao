为什么这是 bug 而不是「凑合能用」
选中「外套」层，把性格从温和改成活泼——然后切到「腿」层，发现性格也是活泼。
玩家会以为「我刚才只改了外套的性格」，实际改了整个人。
反过来更糟：在「头发」层把它调回温和，会把腿上的也改回去，而他不知道自己动了腿。
某个设置改了另一处的东西，就是位置错了。

判断标准一句话：换一个层还看得见，就属于角色；换一个层就消失，就属于层。
「这个角色会不会挥手」换层当然还看得见 → 角色。「这层头发飘不飘」换层就变 → 层。
分图层改吗？不改。一个基准 + 逐项覆盖
性格的意义就是「跨部件一致的节奏」。拆成每层一个，会立刻自相矛盾。
如果手臂性格活泼、腿性格慵懒——走起来是手臂大幅甩、腿慢慢挪，看着像半身不遂。
性格不是「这条腿的性格」，是「这个人走路的样子」。它必须是一个数。
专业版也不要每层一个性格，要「基准 + 覆盖」
character.personality = 'lively'　// 基准，全体生效
character.tune = 0　　　　　　　// 整体再收放一档
character.overrides = {　　　　// 专业版逐项覆盖，空 = 跟随基准
  arm_r: { swing: 2 },　// 这个人右手笨一点
  eyes:  { blink: 'normal' },
  torso: { breath: 0 }　// 这个人体弱
}
为什么用「覆盖」而不是「每层各存一份」：
① 不覆盖的部件自动跟随基准，改基准一下全身就变，不用挨个调 8 次。
② 只需要补差异，多数角色 overrides 是空的。
③ 数据不会打架——永远只有一个基准，一个覆盖表，不会出现「8 个性格哪个算数」。
普通版与专业版各给什么
普通版
四个 chip：活泼 / 温和 / 慵懒 / 紧绷
一条滑杆：更收一点 ↔ 更放一点（−1 / 0 / +1）
结束。
看不见任何 overrides，也不需要知道它存在。
专业版
同样的 chip + 滑杆，作为「基准」
下面多一张表：七个部件 × 各自参数
每格留空就跟随基准，填了才覆盖
